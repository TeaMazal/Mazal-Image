## 已确认并修复

1. **P1：Responses 会忽略禁止调用工具的选项。** `tool_choice:"none"` 仍可能触发图片生成；现在这类请求在提交前返回 400。同时校验图片工具 `action`，强制编辑但没有参考图时拒绝，并把此前被忽略的 `instructions` 加入图片提示词。
2. **P2：Gemini 的 snake_case 参数被忽略。** 原先能识别 `generation_config`，却忽略其内部的 `image_config`、`candidate_count` 等字段，可能按默认尺寸生成。现在统一解析两种命名方式，拒绝冲突、多候选与仅文字输出请求，避免客户端设置与实际出图不一致。
3. **P2：同步等待错误缺少可查询的任务标识。** 超时后的错误响应可能没有 `X-Request-Id` 和 `Location`。现在提交后的错误同时返回查询响应头与 `error.task_id`/`error.task_url`；测试确认等待超时后原任务仍只生成一次，且可查询结果。
4. **P1：并行版本发布漏打包任务恢复修复。** 本次发布前的镜像检查发现最新模板版本含有图片协议模块，但运行中的任务服务仍是旧版，重启加载时会丢弃 API 协议、幂等指纹及原始错误状态；磁盘源码已经修复。已在最新镜像上补回该文件，验证运行文件与服务器源码一致，并通过成功、失败与中断任务的重启测试。没有用旧网关或旧前端覆盖模板版本。
