## 实现与现有版本合并

基于加拿大站当前运行的后端、前端镜像生成增量镜像，只加入协议模块、网关接入、任务元数据持久化及 Nginx 的 v1beta 转发。部署前再次核对镜像 ID 与源码 SHA256，持有共享发布锁，并确认持久化图片队列没有运行中任务；短暂停止新 POST，再等待后端现有 HTTP 请求退出。

保留 Souhub 原有本地管理员引擎策略。仓库现有 `MI_LOCAL_ENGINE_IMAGE_ONLY` 限制属于另一站的既有差异，本次未把该整段代码覆盖到 Souhub。部署后的服务器源码、Dockerfile 和 Nginx 模板均已同步增量修改，后续发布必须以该最新源码为基准。

## 恢复资料

操作目录的 `release-before/` 保存源码、Dockerfile、Compose 和运行 Nginx 配置，`deployment.json` 保存新旧镜像及标签、修改前后源码哈希，`verification.json` 保存无付费验收记录。激活脚本具有失败自动恢复逻辑；手工恢复前须重新核对当前镜像、源码，并等待所有图片任务结束，不得回写用户数据库、账号池或历史任务文件。
