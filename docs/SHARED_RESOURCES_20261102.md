# Souhub 共享服务器资源模式

2026-11-02 已部署至 Souhub。新加坡 Mazal 未部署；共享源码提供可选环境变量和 Compose 覆盖文件，保留站点各自的账号池、用户与价格。

工作台多图在保存各自任务编号后同时执行，已有任务运行时可以继续提交新一轮。每张图仍归属原对话、原轮次，分别按主站规则计费。画布客户端和服务端的两个活动任务上限已取消。

Souhub 后端设置 `MI_SHARED_SERVER_RESOURCES=1`，取消网关执行槽位、任务队列长度、用户活动任务、转发和上传槽位、待处理参考图合计内存的本地上限，以及账号池单账号的本地并发限制。单请求大小校验、鉴权、主站计费、重复请求识别、用户隔离和上游账号可用状态检查保留。主站既有用户规则和上游实际额度、限流仍生效。

生产 `compose.override.yml` 对 backend、canvas、web 设置 `cpus: 0.0`、`mem_limit: 0`、`pids_limit: -1`。Docker 实际返回 NanoCpus=0、Memory=0、PidsLimit=null，表示没有这些容器级配额；共享宿主机可用资源。操作系统与上游能力决定实际容量。维护服务、主站与数据库保持原配置。

## 验收

- 共享前端与生产工作台均构建通过，分别通过 944、943 项测试；画布类型检查、构建和管理后台构建通过。
- 仓库网关 40 项、Souhub 网关 37 项、图片协议 33 项、模板 6 项、站点配置 3 项、维护 4 项、发布 7 项测试通过。
- 画布 Python 11 项、Node 11 项测试通过，包括同时提交六个请求、取消、重复编号不重发和用户隔离。
- 三个绘图容器均 healthy，92 个静态文件哈希通过，公网首页与候选构建哈希一致。
- 验证内部 HTTPS 证书、主站域名解析、引擎鉴权及后台路由隔离；主站与维护容器未重启。
- 本轮没有调用付费上游生图。并发行为使用隔离模拟接口验收，未实测上游最大吞吐量。

生产 gateway 从 Souhub 现有源码应用本轮增量，保留其本地引擎既有模型规则。共享仓库继续保留 Mazal 图片专用规则，两个版本分别测试；没有将 Mazal 整站代码反向覆盖 Souhub。
