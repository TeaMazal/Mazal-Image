# Souhub 最新功能源码同步

2026-10-31 将 Souhub 当前绘图站的功能合入共享仓库。Souhub 仍为功能基准，Mazal 为下游同步站。本次只更新 GitHub 源码，不切换生产镜像，不创建应用版本标签；一键安装器仍固定安装 v0.1.2。

## 合并内容

- 用户端灵感模板中心：分类、搜索、详情、变量填写，可带入独立新对话或当前草稿。覆盖已有草稿前确认，参考图和历史作品保留。
- 24 个内置模板、示例封面与逐项署名，素材采用 CC BY 4.0。模板只填写草稿，不自动生图或计费。
- 管理端 `/templates/`：维护模板、填写项、标签、封面及发布状态，校验重复编号和库版本，避免覆盖并行编辑。
- 输入框自动伸缩并保留失焦后的高度；切换对话后重新测量并从草稿首行显示；桌面工具栏与手机三列参数栏调整。
- 用户端保留灵感模板入口，移除提示词优化入口及组件加载。既有优化模块和受鉴权、限流保护的后端路由保留，不表示用户界面仍提供此入口。
- 使用帮助增加「API 接入」，按当前域名提供地址、模型、生图/改图示例及主站密钥、用量入口。示例只含占位符。
- 图片协议适配与任务恢复：Chat 图片、Responses 图片子集、Gemini 图片格式、异步任务、幂等编号、跨域策略及协议任务元数据，见 [接口说明](IMAGE_PROTOCOLS.md)。

## 合并与部署边界

线上 `frontend/`、`backend/`、`deploy/`、`tests/` 的 596 个文件逐项按内容哈希核对，本地副本与线上全部匹配。共享源码在此基础上保留运行时品牌、下载前缀、引导偏好、本地引擎策略及已有回归测试，未复制站点账号、数据库、密钥或价格配置。

Docker 构建与共享后端发布包含 `image_protocols.py`、`prompt_library.py` 和 `template_data/`；Compose 后端升级时补齐模板、媒体和 v1beta 代理路由，保留线上其余代理配置及 `/embed` 入口。静态宿主机 Nginx 布局仍需按站点审查代理配置，确保 `/templates/`、`/template-media/`、`/v1beta/` 进入后端；不能只替换前端静态资源。
