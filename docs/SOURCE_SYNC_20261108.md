## 下游部署边界

源码包含默认安装器、可选画布集成及主站增量补丁。主站补丁不是通用于任意 Sub2API 版本的一键升级器，应用前须核对版本及哈希。下游单独部署绘图站时应配置自己的公开域名、主站地址和用户鉴权；其主站再使用分配的上游 API Key 调用图片服务。

Souhub 的七模型开放是站点配置；共享后端默认仍仅开放 Image 2。复制仓库不代表其他账号或下游分组自动取得全部模型权限，模型开放与计费须在目标站单独配置和验收。
