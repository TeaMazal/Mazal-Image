## 尚需人工验证与明确边界

- 完整 Web/Codex OAuth 浏览器登录需要管理员实际登录账号；当前只有协议与接口校验通过，不记作完整登录验收。
- 自动额度维护、代理健康维护默认关闭。启用前应确认间隔及管理节点。授权过期且无刷新令牌时仍需重新授权。
- 主站原有代理到期备用策略保留在原代理管理；新绘图页提供固定出口和批量调整，不自动随机换出口，不重放结果未知的生图请求。
- 图片默认保护。解除保护不能自动确认浏览器本地作品引用，UI 已说明这一边界。
- 绘图文件备份不等于主站财务备份；没有浏览器一键恢复生产数据库的功能。

## 备份与回退

`production/precutover-backup` 保存约 313 MB PostgreSQL 归档、全局定义、app-data、Compose、路由、镜像检查记录及绘图元数据。只存服务器私密目录。

主站 `rollback_remote.py` 按入口排空/worker 交接回退程序，保留 PostgreSQL 新写入，不恢复余额数据库。它按 `engine-state.json` 核对本轮已经升级的绘图服务，拒绝覆盖其他并行发布；主站程序回退不回退图片保护或清理服务。

绘图切换脚本在失败时恢复旧 API 镜像，同时保留新保护逻辑的清理服务。完整手动回退也必须保留或暂停清理服务，防止旧清理逻辑删除已保护图片。恢复源码与镜像不覆盖新作品、不重新启用旧账号池或渠道 725。
