# Souhub 画布与内部回源源码同步

本次将已上线的 Souhub 画布及后续修复保存到现有共享仓库，保留两站原有的默认构建和稳定版安装器。没有同步生产账号、数据库、密钥、证书或运行快照，也没有对其他站点重新部署。

## 已同步内容

- 画布前端及其依赖锁、上游 MIT 许可和源码来源记录。
- 主站用户身份验证、私有项目与素材、云端同步冲突副本、任务持久化与恢复、项目 ZIP 导入导出。
- 工作台与画布作品互通覆盖文件，独立保存在集成目录，避免在没有画布服务的站点出现不可用入口。
- 参考图在读取前检查既有大小限制；空闲任务监视器不读取整份历史；错误 JSON 返回 400。
- 上游请求失败和明确超时的工作台提示修复，合回共享前端。
- 独立内部 HTTPS 网络、原引擎密钥鉴权、有效证书校验及证书续签重载的配置示例与运维步骤。
- 源码打包排除画布运行数据和临时生成的工作台目录，避免把素材、数据库或构建副本带入源码归档。

## 验证与限制

Souhub 上线验收时工作台 941 项测试通过；画布同步与导入导出 10 项、后端 10 项专项验证通过，画布前端类型检查和构建通过。

此次仓库合成检查：共享工作台和应用画布覆盖文件的工作台分别通过构建及 942 项测试；画布类型检查、构建与上述 20 项专项测试通过；发布与源码归档检查 7 项通过。

内部回源修复后，实际生成一张中国龙图片，约 14 秒成功；主站计费一张，实际费用 $0.03，测试密钥额度减少 $0.03。内部访问日志确认成功请求经过内部网络；无效引擎密钥和普通用户密钥不能直接调用引擎，内部管理路径返回 404。主站、账号池后端和画布服务没有因本次回源修复重启。

这些是对应 Souhub 生产版本的验收结果，不代表其他站点已经部署或独立执行了全部交互验收。此次 GitHub 合成源码的检查结果以本次提交和 GitHub Actions 为准。

主站当前手工发布容器，替换容器时需在切流前恢复 `souhub_image_bridge` 连接并验证内部域名解析。独立异地备份、画布任务与主站账单请求编号的精确关联仍属于后续事项。

构建、目录布局与运维入口见 [画布集成](../integrations/canvas/README.md)。不要用旧的普通工作台发布包覆盖 Souhub 已上线的画布网关。
