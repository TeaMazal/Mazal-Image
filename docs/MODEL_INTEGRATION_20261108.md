Web 账号沿用已有 Image 2 路线。Codex 新增模型使用原生 images 生成/编辑接口，不因失败自动换成 Image 2 或 Responses。不能根据 Free、Plus、Team 计划标签直接承诺全部模型可用。

能力证据按账号、模型、生成/编辑分别保存；生成成功不会自动获得编辑权限。模型列表与调度均检查完整账号身份、模型映射、分组和调度策略。修复了精简调度快照缺少身份字段导致验证失配的问题。

账号身份、模型映射、代理绑定变化后，旧证据不再匹配；常规 access token 续期保留证据。明确的访问拒绝或冲突模型声明使对应能力失效；限流、普通参数问题及结果不确定不抹掉此前成功证据。证据文件不保存令牌。

共享后端默认仍只开放 Image 2，Souhub 的部署环境显式启用七个名称。用户最终可见模型来自主站授权接口，参考图编辑使用独立授权列表。

## 用户和管理行为

用户工作台增加模型选择、按模型查询报价、编辑能力提示和历史模型记录。报价缓存按密钥和模型隔离，异步返回的旧模型报价不能覆盖当前模型。按用量计费的渠道显示实际用量结算，不虚构固定单张价格。

保留独立对话、同轮多图分批归组、整轮操作、标题与滚动定位、参考图和无限画布。修复请求头处理丢失对话、轮次及预计张数的问题。

管理测试与用户生成记录保存实际执行账号、代理、映射模型、上游接口，以及上游明确声明的模型（如有）。用户成功图片的记录与账单使用同一规范请求编号，能从作品查看真实流水。原图和缩略图仍需管理权限。

同一用户相同任务编号、相同请求内容返回原任务；改变模型、参数、参考图或遮罩返回 409。旧任务无法证明内容一致时只允许查询，不能借重试产生新生成。任务重启后保留指纹、错误类别、对话及结果状态。

上游 5xx、代理连接中断或服务重启导致的未知结果显示“待核对”，不自动重新提交，也不宣称上游已停止。独立的新任务仍可由用户明确提交。

## 源码应用与恢复

共享改动位于 `frontend/`、`backend/`；Souhub 画布与品牌差异继续使用 `integrations/canvas/workbench-overrides`。主站补丁及管理页面模块位于 `integrations/model-integration`。补丁应用器先核对基线哈希；发现其他修改须先合并，禁止整站旧包覆盖。

本轮没有数据库结构迁移。恢复必须保留 PostgreSQL、用户作品、能力证据和最新任务文件，禁止回写部署前账单或任务快照。

仅回退最后的嵌入页修正时，可将 Compose 的 web 镜像固定为 `sha256:2f58208ca7e0b3090adbe849fd2dac4d285c944b4a682092e22af21fdee692de`；它保留 r32 工作台与 `/embed` 路由，但含旧内联来源，适用于应急恢复。操作前重新核对当前镜像和任务、排空请求；替换后确认 Nginx 没有遗留 POST 503 排空规则。

主站分阶段切换、排空和后台工作者交接脚本已留在操作目录及 `production/review` 记录中。整套回退须重新核对当前指针、保护服务和账号能力状态，按入口切换、排空、工作者交接、持久化顺序处理；这些历史脚本不是未经检查即可重放的一键安装器。本轮验证了失败时的 web 镜像恢复，未将正式主站退回旧版本做演练。
